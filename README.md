## 🚀 Key Projects

### 🚗 DocRoad: Roadside Assistance Platform
*University of Moratuwa group project · 2026*

A real-time platform that connects stranded drivers with nearby mechanics. It has four parts: a driver app, a mechanic app, a backend API, and a web admin dashboard.

- 📍 **Live matching and tracking:** ranks nearby mechanics in real time and shows live location tracking on maps.
- 🆘 **Emergency SOS:** sends SMS alerts to emergency contacts.
- 💬 **In-app chat** between driver and mechanic, plus **push notifications** (FCM).
- 🤖 **AI help:** Google Gemini, called through the backend, helps diagnose vehicle problems.
- 🌏 **Sinhala and English** interface in both mobile apps.
- 🛡️ **Admin dashboard** with a live map and reports, and locked-down Firestore security rules.
- **Tech:** Flutter · Node.js/Express · Socket.IO · Firebase (Auth, Firestore, FCM) · PostgreSQL · MongoDB · React · Leaflet · Docker

### 📈 ProChart: Real-Time Trading Chart
*Personal project · 2026*

A rewrite of my old vanilla-JS trading chart, now in React 19 and TypeScript with a feature-based structure. Version 0.1 is released.

- 🕯️ Live candles streamed over WebSocket, several chart types, and symbol search.
- 📊 Overlay and pane indicators (Bollinger Bands, SMA, RSI) with **RSI divergence detection**.
- ✏️ Drawing tools, a watchlist, price alerts, and simulated orders.
- 🔔 **Candle + Bollinger Band reversal alerts**, sent to **Telegram 24/7** from a Node server on an **Azure VM**.
- ⚙️ CI on every pull request and automatic deploys to **Azure Static Web Apps** with GitHub Actions.
- **Tech:** React 19 · TypeScript · Vite · Tailwind CSS v4 · Zustand · Lightweight Charts · Vitest · Azure
